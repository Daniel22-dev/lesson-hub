# Grafické podklady

Do této složky patří oficiální školní logo a případné další schválené grafické prvky AI Studia.

Po vložení loga nastavte jeho relativní cestu v `src/core/config.js`, například:

```js
schoolLogoUrl: './src/assets/logo-skoly.svg'
```

Současný monogram `LH` je pouze dočasná náhrada, protože oficiální logo nebylo součástí dodaných podkladů.
