# Bezpečnost Lesson Hubu

Bezpečnostní nálezy nezveřejňujte jako veřejný GitHub issue, pokud by popis umožnil zneužití. Předejte je přímo správci aplikace Danielu Balážovi interním školním kanálem.

Do hlášení nevkládejte skutečná data studentů, přístupové tokeny, hesla ani SMTP údaje. Pro ověření používejte anonymizovaná testovací data.

Podporovaná větev: aktuální `main`. Opravy kritických zranitelností mají přednost před dalšími funkcemi.
