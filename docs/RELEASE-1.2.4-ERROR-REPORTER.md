# Lesson Hub 1.2.4 — reportér a P2 unifikace

Verze **1.2.4** zachovává kanonický reportér GHRAB 1.1.0 a současně sjednocuje Lesson Hub s platformou GHRAB 1.0.0.

- reportér se načítá best-effort a není podmínkou startu;
- jedna lokální instance, centrální instance je vypnuta;
- ZIP diagnostika v3, focus trap, bezpečné URL a omezená Gmail URL;
- jednotné logo, patička, motiv a storage namespace;
- zálohy Lesson Hubu používají GHRAB artifact envelope se SHA-256;
- starší JSON zálohy zůstávají importovatelné;
- cache `ghrab-lesson-hub-v1.2.4` a řízená aktualizace.
